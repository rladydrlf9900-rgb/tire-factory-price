# 타이어공장도가격

타이어 공장도가격을 **누구나 무료로** 조회하는 사이트. 로그인 없음.

> **이 문서는 다른 컴퓨터에서 이어서 작업하기 위한 인수인계서입니다.**
> 새 컴퓨터에서 이 저장소를 받은 뒤, 이 파일을 처음부터 읽으면 됩니다.

---

## 1. 이게 뭐고 왜 만드나

- **무엇** : 한국·금호·넥센·미쉐린 등 전 브랜드 타이어의 공장도가를 규격별로 조회하는 사이트
- **누가 쓰나** : 타이어 매장 하는 사람 누구나. **로그인·회원가입 없음**
- **왜 만드나** : 나중에 만들 **타이어 POS SaaS 광고를 여기에 붙이기 위한 유입 창구**.
  그래서 사이트 자체는 무료로 열고, 트래픽이 많을수록 좋다. 가격표가 통째로 긁혀도 상관없다.
- **홍보 방식** : 검색 노출(SEO)보다 **네이버 검색광고**를 쓸 계획

## 2. 지금까지 정해진 것 (다시 논의하지 말 것)

| 항목 | 결정 |
|---|---|
| 로그인 | **없음.** 누구나 바로 조회 |
| 표 컬럼 | `제조사 · 모델 · 제품명 · 규격 · 계절 · 공장도가 · DC율 · 할인가` 만 |
| 모델 / 제품명 | 모델 = `AU7`, 제품명 = `엔페라` (헷갈리기 쉬움) |
| DC율 | 사용자가 **직접 입력**하는 칸. `할인가 = 공장도가 × (1 − DC/100)` |
| DC율 초기값 | **항상 빈칸(0%)**. 검색·필터·페이지 이동하면 초기화 |
| 관리자 진입 | 주소 분리 안 함. **왼쪽 위 로고 마크 클릭 → 비밀번호** (초기 `1234`) |
| 관리자 화면 | 통계·탭 없이 **제조사별 업로드 박스**만. 번호칸으로 순서 변경 |
| 광고 자리 | **오른쪽 위 한 곳만**, 가로로 작게. 비어 있으면 화면에 안 보임 |
| 홈 화면 | 제목·설명문·푸터·바로가기 링크 **전부 없음**. 검색창 + 표만 |
| 규격 페이지 | 제목 유지 (`245/45R18 타이어 공장도가격`) |
| 서버 | 가비아 웹호스팅 (PHP + MySQL) |

**지운 것들** (다시 넣지 말 것) : 양식 내려받기 버튼, 전체 지우기, 필터 숫자(건수),
폭·편평비 선택칸, 재고·갱신일·발주 컬럼, 정렬 드롭다운, 총건수 표시, 푸터, 규격 바로가기 목록

## 3. 어떻게 돌아가나 (구조)

핵심은 **가격표 전체를 정적 파일 하나로 내려주고, 검색은 브라우저에서 하는 것.**
서버는 파일 하나만 주면 되므로 사람이 몰려도 버틴다. (동시 1만 명 목표)

```
가격표 업로드 (관리자)
   ↓
MySQL 저장  +  assets/price.json 자동 생성   ← 16,238품목이 압축 후 60KB
   ↓
방문자는 price.json 만 받아감 → 검색·필터·페이지 전부 브라우저에서 처리
```

### 폴더

```
웹/                 ← 이 폴더 "안의 내용"만 FTP 로 가비아에 올린다
  index.php         홈
  view.php          규격별(/245-45-18) · 제조사별(/brand/한국) 페이지
  sitemap.php       검색엔진용 주소 목록
  설정.php           ★ DB 접속 정보 — 서버마다 다르게 채운다
  .htaccess         주소 규칙 · 압축 · 캐시
  api/admin.php     로그인 · 업로드 · 되돌리기 · 순서변경 · 다운로드
  lib/              db · auth · sheet(엑셀읽기) · parse(칸 해석) · page(화면) · admin_ui
  assets/           style.css · app.js · price.json(자동생성)
  data/             업로드 원본 · 캐시 (권한 707 필요, git 에는 안 올림)
설치/schema.sql     ← phpMyAdmin 에 붙여넣어 표 만들기
설치안내.md          ← 가비아에 올리는 순서
시안/               처음 만든 화면 그림 (참고용, 서버에 안 올림)
테스트/              서버 없이 브라우저만으로 돌아가는 옛 버전 (참고용)
자료/                엑셀 가격표 넣어두는 곳
```

### 엑셀 업로드가 알아서 처리하는 것

- 칸 순서가 달라도 **제목을 보고 찾아냄** (`공장도가`/`단가`/`매입가`/`가격` 다 인식)
- `235-45-18`, `245/40/19` → `235/45R18`, `245/40R19` 로 정리
- `168,000원`, `₩152500` → 숫자로
- `올시즌`→사계절, `썸머`→여름, `윈터`→겨울
- 못 읽은 줄은 "6번째 줄 — 가격이 비어 있음" 처럼 알려줌
- 올리면 **새 품목 / 가격 변경 / 그대로 / 없어짐** 건수를 보여줌
- 1MB 넘는 파일은 **조각내서** 전송 (호스팅 용량 제한 회피)
- 10,000행 기준 **0.25초**


### 화면만 보고 싶을 때 (서버 없이)

`테스트/index.html` 을 크롬으로 열면 된다. (옛 버전이지만 화면 감각 확인용)

### 진짜 사이트를 돌려보고 싶을 때

PHP 8 이상이 필요하다. (`winget install PHP.PHP.8.2`)
MySQL 없이 돌려보려면 SQLite 로 바꿔 띄우는 스크립트가 필요한데, 이건 임시 파일이라
저장소에 없다. **AI 에게 "미리보기 띄워줘" 라고 하면 다시 만들어 준다.**

### 가비아에 올릴 때

`설치안내.md` 를 순서대로 따라가면 된다.

## 6. 검증 기록 (이미 확인된 것)

실제로 PHP 서버를 띄우고 10,000행 엑셀로 테스트한 결과다.

| 항목 | 결과 |
|---|---|
| 10,000품목 업로드 | 0.25초 · 메모리 14MB |
| 100품목 추가 + 50개 가격변경 재업로드 | 새 100 / 변경 50 / 그대로 9,950 / 없어짐 0 ✓ |
| 추가분만 올리는 실수 | 10,100건 사라진다고 경고 ✓ |
| 되돌리기 | 10,100건 복구 ✓ |
| 가격표 정적 파일 | 16,238품목 → gzip 60KB |
| 규격 검색 | 즉시 (서버에 안 물어봄) |
| PC 화면 | 모바일 수정 후에도 픽셀 단위로 동일함 확인 |

**과거에 실제로 났던 버그** (다시 만들지 말 것)

1. **PHP 파일에 BOM** 이 붙으면 관리자 로그인이 아예 안 된다. 오류 메시지도 안 뜬다.
   → 파일 저장할 때 항상 **BOM 없는 UTF-8** 로.
2. `var Q = null;` 선언이 사용처보다 아래에 있어서 규격 페이지 필터가 통째로 풀렸다.
3. 표 헤더에 `position:sticky; top:58px` 을 주면 가로스크롤 컨테이너 안에서 첫 줄을 가린다.
